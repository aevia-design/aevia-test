# Plan 11-02 — Firestore Schema + `getOrderAssets` Cloud Function

## Objective
Two things in one plan (both small):

1. **Schema fix:** Add `fpSelections` (structured array of addon slugs) to what order.html sends and Firestore stores. Currently this lives only as prose in `specialRequests`.
2. **Cloud Function:** Implement `getOrderAssets` so the template engine can fetch a full order (metadata + signed GCS read URLs) by order number.

## Context
- @pages/order.html — order form; sends `fpTexts` (already) but not `fpSelections` as a structured field
- @functions/upload.js — `createUploadSession`; saves `fpTexts` (already) but not `fpSelections`
- @functions/index.js — function entry points; `getOrderAssets` does not exist yet
- @functions/package.json — firebase-admin, firebase-functions already installed; no new deps needed

## Current Firestore document structure (what's saved today)
```
orderNumber, customerName, email, templateName, pageCount,
status, createdAt, folderName, specialRequests (text blob),
photoNotes, fpTexts (structured object, already saved ✓)
```

## GCS file path convention (already enforced by upload.js)
- Cover photo:       `{folderName}/cover/cover.{ext}`
- Special FP photos: `{folderName}/special_pages/{addonSlug}.{ext}`  (e.g. fp1.jpg, fp3-0.jpg)
- Main pool photos:  `{folderName}/photos/photo_{001}.{ext}`

FileType and addonSlug are **inferrable from the GCS path** — no GCS object metadata needed.

## Task 2 — Implement `getOrderAssets` Cloud Function

Add to `functions/index.js` (import pattern same as existing functions — read index.js first):

```js
exports.getOrderAssets = functions.region('europe-west1').https.onRequest(async (req, res) => {
  // CORS headers — copy exact pattern from createUploadSession
  // Accept POST only

  const { orderNumber } = req.body;
  if (!orderNumber) return res.status(400).json({ error: 'orderNumber required' });

  // 1. Fetch Firestore document (orderNumber is the doc ID)
  const doc = await db.collection('orders').doc(orderNumber).get();
  if (!doc.exists) return res.status(404).json({ error: 'Order not found' });
  const order = doc.data();

  // 2. List all GCS files under the order's folder
  const bucket = storage.bucket(BUCKET_NAME);
  const [allFiles] = await bucket.getFiles({ prefix: order.folderName + '/' });

  // 3. Generate signed read URLs (1 hour expiry)
  const expiresAt = new Date(Date.now() + 60 * 60 * 1000);
  const files = await Promise.all(
    allFiles
      .filter(f => !f.name.endsWith('/'))  // skip folder placeholder objects
      .map(async f => {
        const [url] = await f.getSignedUrl({ action: 'read', version: 'v4', expires: expiresAt });
        const parts = f.name.split('/');
        const filename = parts[parts.length - 1];
        const section = parts[parts.length - 2];  // 'cover', 'special_pages', or 'photos'
        let fileType, addonSlug;
        if (section === 'cover') {
          fileType = 'cover'; addonSlug = null;
        } else if (section === 'special_pages') {
          fileType = 'special';
          // slug is filename without extension, e.g. 'fp1', 'fp3'
          addonSlug = filename.replace(/\.[^.]+$/, '').replace(/-\d+$/, '');
        } else {
          fileType = 'main'; addonSlug = null;
        }
        return { name: filename, url, fileType, addonSlug };
      })
  );

  // 4. Return
  res.json({
    order: {
      orderNumber: order.orderNumber,
      customerName: order.customerName,
      email: order.email,
      templateName: order.templateName,
      pageCount: order.pageCount,
      fpSelections: order.fpSelections || [],   // array of slugs: ['fp1', 'fp3']
      fpTexts: order.fpTexts || {},             // structured: { fp2: ['word1','word2'], fp3: 'My text' }
      customerNotes: order.photoNotes || null,
      status: order.status,
      createdAt: order.createdAt,
    },
    files,
  });
});
```

Deploy and test:
```bash
cd functions && npm run deploy

curl -X POST https://europe-west1-aevia-uploads.cloudfunctions.net/getOrderAssets \
  -H "Content-Type: application/json" \
  -d '{"orderNumber": "AEV-001"}'
```
