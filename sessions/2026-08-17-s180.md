### The one code change: `composeDe`

Two templates had English words baked **inside** `compose()` — a function in the data file, not a
data field — so no amount of `labelDe` could reach them. `order.html:2497` now prefers
`textMeta.composeDe` when the order is German, same fallback rule as everything else.

Tender's and Heirloom's German there is **Xenia's authored book text, verbatim** from the `*_DE.txt`
files. Note it is **not a token-swap of the English**: German puts the verb at the end, so the
opening sentence reorders around the date and place and takes no comma after the date. A naive
translation layer would have produced nonsense.

Every other composer only interleaves the customer's own words, so needs no twin. A test asserts
that: if one grows English prose of its own without a `composeDe`, it fails.

### The gate

The real guard is a **sweep over all eleven templates at once**
(`tests/de-template-strings.test.js`), because `tdText()`'s English fallback makes a missing
translation **silent** — the customer just sees an English label on a German form and we never hear
about it. **Verified it can fail** by deleting one `labelDe` from Wander; it named
`cover.front.labelDe` precisely.

**Watch out for:** restoring that deliberate failure with `git checkout <file>` reverted the whole
file and wiped the German written minutes earlier. Re-applied and re-verified. Use a targeted
revert, not the file.

**Watch out for:** `joyride-data.js` is **CRLF** while the other data files are LF. A multi-line
search string matched zero times until the replacement script was made line-ending aware. Do not
convert the file — a wholesale conversion diffs every line and buries the actual change.

## The font finding — NT Somic has no ß

Captions and cover text are **printed**, so German needs ä ö ü Ä Ö Ü ß in the actual font file, and
**a missing glyph does not throw** — the renderer substitutes another face or draws nothing.

`scripts/check-font-glyphs.mjs` (new) reads the TrueType `cmap` table directly, no dependency.
82 files, all twelve families the data files name. Result: **everything fine except NT Somic, which
has ä ö ü and é but no ß.** Verified twice with independent code. All fonts carry „ and “.

That matters because **NT Somic is Scribble's default caption font on every spread** — exactly where
German AI captions land in Stage 5. And it had already bitten us: the `placeholderDe` written an
hour earlier read **"Unsere süße Ann"**, with a ß, in NT Somic. Now "Unsere kleine Ann", with the
constraint recorded beside the font picker.

**Owner's call (S180): replace NT Somic for Scribble with a face that carries ß.** → TO-DOS #115.
Fallback if no replacement is found: default German Scribble captions to EB Garamond, already in
Scribble's picker and carrying ß. **Not** substituting "ss" — valid in Switzerland, wrong in Austria.

`tests/de-font-glyphs.test.js` guards both halves: no German string we ship is set in a font that
cannot render it, and the known-gap table still matches the font file, so a re-cut NT Somic makes
the test tell us to drop the workaround rather than leaving a stale comment.

## Stage 5 — the German caption guide (written, not wired)

One file, not two: the German section lives inside `functions/caption/caption-voice.md` so the
function keeps loading a single system prompt. A separate file would mean choosing which to load and
the two would drift.

Register was derived from **Xenia's four authored `*_DE.txt` files**, not invented.

**⚠ The most useful thing found: her predefined book verses are a DIFFERENT GENRE from captions.**
The Newborn star-sign blessings ("Möge dein Herz voller Staunen und Liebe sein") and the wedding
intro ("Der Anfang von für immer") are elevated and deliberately sentimental, written once for a
fixed page. A caption in that voice is greeting-card writing and breaks the guide's own rules. The
guide now says explicitly: take the warmth and the directness, not the form.

Also recorded because it cuts against us: Xenia writes **"Willkommen auf der Welt, Nico!" with an
exclamation mark**, which both voice sections forbid. Fixed book text, not a caption, so not a
direct conflict — but **her German is warmer than our caption rules allow, and the caption rules are
ours, not hers.** Worth deciding whether ours are too austere for a baby book.

### The Ein/Eine rule — invented, challenged, researched, withdrawn

Owner challenged one rule: *"do not start with Ein/Eine — is that really slop in German?"* He was
right. `/deep-research` run; note at **`work/german-caption-voice/research_v1.md`** (14 sources).

**No German style authority treats a sentence-initial indefinite article as a defect.** The rule had
been invented by analogy with the English "no A/An" rule, which exists for reasons particular to
English. The burden of proof sat on the invented rule.

**Then the owner rejected the sourcing of the fix, also correctly.** Two of the sources are
professional **journalism** guidance, where a caption's job is to inform; Aevia's is to evoke. The
note itself said so and then leaned on them anyway. Re-grounded on in-genre, in-brand evidence:
Xenia's German has exactly two fragments — *"Unser süßer kleiner Bub."* and *"Der Anfang von für
immer."* — **both led by a determiner, neither a bare noun.** Better evidence than any handbook,
because it is the right genre and the right voice.

What survives from research: **Nominalstil** as the primary target is well founded (Wolf Schneider,
*Deutsch für Profis*); the German LLM tells the invented list had missed —
**"nicht nur…, sondern auch…"**, the opening formulas ("In einer Welt, in der…"), and marker
vocabulary ("ganzheitlich", "umfassend", "eintauchen"); and the German test for a Floskel —
**does the phrase put a picture in the reader's head?** The one rule with no source, **"einfangen"**,
is now labelled in the guide as our judgement rather than a finding.

**Nothing supports either way whether an Aevia German caption should open with "Ein/Eine".** No
in-brand example exists. Keeping it as a house preference is a legitimate brand-voice call; it just
cannot be presented as a German style rule.

**Watch out for:** the guide is a **prompt** — it fails silently when edited. `tests/caption-voice-de.test.js`
pins the decisions, including the withdrawal itself, so nobody reasoning from English re-adds the
rule. It earned its place immediately by catching one of my own examples starting with "Ein".

**Watch out for a German-specific test trap:** `/\bSie\b/` cannot detect formal address. At the start
of a sentence German capitalises "sie" (she) anyway, so *"Sie hat alles verschlafen"* is correct
third person. Only a capitalised Sie/Ihnen/Ihre **mid-sentence** is unambiguous.
