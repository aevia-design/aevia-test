## Key UX decisions (settled this session)
- **Hero 4:3 locked** for all templates (5:4 dropped; `front54.webp` deleted).
- **Thumbnail balance rule** (in `product.js`, automatic for any count): thumbs keep a fixed size
  (= one thumb in a full 6-across row). ≤6 → one centred row; 7+ → two equal rows of `ceil(n/2)`,
  both centred, so an uneven bottom row (4+3, 5+4, 6+5) sits centred — no orphan. Kseniia OK'd.
  (Considered AU-style single-row filmstrip; rejected — 11 thumbs would be too small.)
- **Centralize at merge, not during experimentation** — kept CSS page-local while building each
  `-exp2` so a template could diverge if it fought the pattern; none did.
