### 11:30 — A caption cut named as a WORD was only read as a NUMBER
**Decided:** Fixed at root cause with a shared `COVER_STYLE_WEIGHTS` map in BOTH
`template-engine.html` and `customer-preview.html`, mirroring `FONT_WEIGHT_KEYWORDS` in
`export-pdf.js`.
**Why:** A cover caption declares its cut as a numeric `weight` (Newborn, Papercut) or as
a `style` STRING (Joyride, Laguna — the form Xenia's CSVs use). Both screen surfaces read
only the number and fell back to 400, while the PDF honours the string. **Print and screen
disagreed, and only the print is real.** Laguna's bold title made it visible.
**Watch out for:** This was NOT a parity gap — both engines had it, so mirroring one into
the other would have copied the bug. Also: it surfaced only because S168 added
`Mulish-Regular.ttf`. Before that, Joyride's `style:'light'` subtitle resolved to 400,
found no 400 face and fell back to Light, so screen matched print **by luck**. **Adding a
font cut is not additive — it can change what existing templates render.**

### 13:20 — Region maps must be 206mm, and were not
**Done:** Found during the stage 7 read-through; the artist re-issued all six as 206mm
PNGs the same day. `laguna-data.js` now points at `.png`; the six map entries were removed
from `optimise-laguna-rasters.mjs` (flat PNGs have no base64 blob, and the stale `.svg`
names would throw ENOENT).
**Why:** Region maps are the ONE asset the code does not viewBox-expand — it resizes them
straight to the 206mm bleed canvas. A 200mm map is stretched ~3%, and since Laguna carries
Wander's pin table byte-identical, the pins drift outward, up to ~3mm at the map edges.
**Watch out for:** The artist was not wrong that she drew 206mm of artwork — widening the
old SVG's viewBox by 3mm revealed a fully painted bleed. **Illustrator's SVG export writes
the ARTBOARD and clips the bleed away**; exporting as PNG carried it through. Verify by
measuring, not by asking: old EU map aligned to Wander at scale **0.9725**, new one at
**1.0000**. Everything else in a drop is correctly 200mm.
