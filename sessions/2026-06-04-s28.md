### Wander cover bleed bug (cover SVG viewBox) — RESOLVED
- Symptom: wrong colour at the cover's side bleeds. **Root cause:** Wander's cover SVG
  (made in Affinity; everything else in Illustrator) had its `viewBox` set to the
  FULL-BLEED rect (`0 0 5245 2788`, ratio 1.881) instead of the content rect. Engine
  forced it into the 1227×600 content box → distorted + background gradient leaked at edges.
- **Fix (asset-only):** Kseniia/Evgeny reframed viewBox to `212.598 212.598 4818.9 2362.2`
  (content). Verified in engine: cover renders edge-to-edge, no leak, overlay ratio 2.041.
- **The bleed model is now documented** (memory `project_bleed_model.md`): data coords are
  WITH bleed/centre; SVG viewBox frames CONTENT only (bleed artwork outside); engine
  subtracts bleed; PDF re-expands viewBox (`expandSvgViewBox`) + uses with-bleed coords.
  Confirmed correct by Evgeny. Spreads were never affected (their viewBoxes already content).
