### 17:10 — COVER_FULL_W_MM crash — PDF broken for every template
**Done:** Deleted three dead assignments in `initPrintConstants()` (`scripts/export-pdf.js:128`).
**Why:** S152 removed the module-level `COVER_FULL_W_MM` constant — correct, since the cover width
became per-render — but left `COVER_FULL_W_PX = Math.round(COVER_FULL_W_MM * MM_TO_PX)` behind. It
runs at the start of every render, so it threw `ReferenceError` before any drawing. **Not
Tender-specific: it broke all six templates.** All three globals (`COVER_FULL_W_PX`,
`COVER_FULL_H_PX`, `COVER_BLEED_PX`) were already dead — `renderCoverImage()` derives its own
`..._LOCAL` values — so this is a deletion, not a substitution.
**Watch out for:** 252 unit tests passed throughout, because they call `computeCoverDimensions()`
directly and never invoke the init path that crashed. The whole cover pipeline still has no smoke
test that actually runs init. Owner's first render found it in seconds.

### 17:30 — Caption box sizes moved into the cover CSVs
**Done:** `captions1_width/height` + `captions2_width/height` now present and populated in all six
cover CSVs. Only one value actually changed on sync: Tender's spine `wMm` 45 → 120.
**Decided:** Rotated spine rows use the **artboard frame** — `width` = across the spine (small),
`height` = along the spine (long). The engine's own frame is the opposite (pre-rotation, width =
reading direction), so the sync **swaps them for rows whose `Captions_1_direction` says "Rotate all
text 270 degree"**.
**Why:** The two files that already had these columns disagreed with each other — Newborn and
Joyride used the artboard frame, Wander used the pre-rotation frame. No precedent existed, so one
had to be chosen. Artboard won 2-to-1 and is what Xenia measures in Illustrator. Wander's spine was
converted (`65/5` → `5/65`).
**Watch out for:** `hMm` is **inert everywhere except Joyride** — the render code only reads it when
`valign` is top/bottom (no cover caption uses that) or when `autoShrink: true`. The heights now in
the CSVs are recorded but do nothing until autoShrink is switched on. Also: for `align: left/right`
captions, changing width **moves the text**, because it is pinned to a box edge, not the centre.
Wander is the only template affected (front `right`, spine `left`).

### 17:50 — Local dev server: CLAUDE.md was wrong
**Done:** CLAUDE.md now says `npx http-server . -p 8080 -c-1`, matching LINKS.md.
**Why:** CLAUDE.md said `npx serve`, which LINKS.md had already documented as wrong. `serve` 404s
and **strips the `?token=` query locally** — so a preview page loads but silently behaves as if the
order does not exist. CLAUDE.md is read at the start of every session, so the stale line would keep
re-introducing the mistake.
**Watch out for:** Clean URLs (`/pages/staff/template-engine`) are a **Cloudflare Pages rewrite**.
They 404 locally on both servers. Local always needs the `.html` form.
