## 2. Typography system (P1 from the design review)

- Owner felt the site fonts were generic/tiny. Root cause: site chrome used **Georgia (system serif) + the OS system-sans stack at 15px** + lots of 10–11px uppercase grey micro-labels — no real type identity, renders differently per OS.
- Spawned a research agent (Papier/Artifact Uprising/Aesop/Kinfolk) → recommendation: **Lora + Inter, 17px body**. Previewed on our-artists.html first; Evgeny approved ("like it better").
- **`assets/css/type.css`** (new) = **single source of truth**: `@import` Lora + Inter, overrides `:root --serif/--sans`, sets `body{font-size:17px}`. Linked AFTER each page's inline `<style>` (right before `mobile.css`) on all 15 customer pages so it wins the cascade. our-artists.html refactored to use it too (dropped its bespoke font `<link>`); headings normalised to weight 400 (were 500) to match the rest of the site.
