## Key decisions
- **Navigation = linear-forward / free-backward.** Each step validates on Continue; `advance()` is the SOLE extender of `furthestReached` so a step can never be reached without passing its predecessor's validation; visited stepper segments are clickable to go back/edit. Backed by S51 deep-research (Baymard: 15-field form across 3 logical steps beats 10-field single page by 11–14%; NN/g cognitive-load; 3–7 steps is the sweet spot).
- **Special step auto-skips** when the order has no active add-ons (data-driven from `ORDER.addons` minus `cancelledAddons`).
- **S40 upload-hardening path NOT touched** — `beforeunload`/`uploadInFlight`, worker pool, `confirmUpload`, progress overlay all stay inside the Photos step unchanged. The refactor is presentational.
- **Extensibility seam:** each step is a self-contained `<section class="form-step">` so the future "preview my data" panel (à la Wander map) can slot into Cover/Special without touching the engine. Explicitly out of scope this session.
- **Did NOT use decomposing-work/developer-agent** — single tightly-coupled file; subagents would re-derive the same context and collide on one file. Built inline.

1. **Wander country select autofilled "Austria"** (Chrome ignores `autocomplete="off"` on country-shaped fields; Vienna user → profile country). 3. **Wander "Your route" itinerary inputs moved ABOVE the spread preview** (data before result).
4. **Newborn product page** (`newborn.html`): Intro + Labour spreads now start **unticked** (opt-in).
