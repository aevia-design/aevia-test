## What was fixed (UNCOMMITTED on working tree)

### Caption parity — staff engine vs customer preview (Intro text panel)
Evgeny's E2E surfaced the Newborn Intro caption rendering differently staff vs customer.
Root-caused via live measurement (curl `getOrder` for saved styles + Playwright-measure the
real customer DOM — `qa/measure-intro-panel.mjs`, new). **Two stacked bugs:**
1. **Dropped style fields** — the text-panel render block read back only
   font/sizePt/lineSpacing/letterSpacing, omitting **weight + italic**. Staff looked italic
   (toolbar set it live on the element) but customer rendered roman. Fixed both engines to
   read all six fields w/ CSV `style` fallback, mirroring the per-photo caption block.
   (`customer-preview.html` ~2064, `template-engine.html` ~2775.)
2. **Font-size formula divergence (real root cause)** — the toolbar live-apply used the
   canvas-scaled `sizePt*SCALE*25.4/72` px, but the render used raw `sizePt+'pt'` (=
   sizePt*96/72 px ≈ 26% too big on the 3px/mm canvas). "Fits while editing, overflows on
   reload/customer." Fixed both render blocks to the scaled formula (funnyWords unchanged).
   **Verified:** customer panel measured 21.3px→16.9px after fix, italic, = staff toolbar.

### PDF parity — 3 bugs from Evgeny's first Newborn PDF print
1. **Intro panel ~26% too big in PDF** — `export-pdf.js` multiplied panel size by
   `PANEL_PT_SCALE≈1.26`, a fudge that compensated for the engine's OLD raw-pt bug. Now that
   the engine renders true physical size, removed the fudge → panel draws at raw `sizePt`
   like the per-photo captions. Engine = customer = PDF. (`export-pdf.js` ~768.)
2. **Labour photos missing in PDF** — two parts:
   (a) PDF didn't handle `slot.pool === 'labour'` → fell through to the main pool. Fixed to
   treat `'labour'` like `'artwork'` (per-side array, index by side). (`export-pdf.js` ~382.)
   (b) **Engine Export collapsed every special key except FP5 to a single filename** →
   `FPlabour` lost its 2nd photo (book-state had string `"fplabour-0.png"`). Made the export
   **data-driven**: any spread whose slots use an `artwork`/`labour` pool now serialises as a
   `[left,right]` array. Generic fix so the next per-side template won't recur.
   (`template-engine.html` ~1377.) **This is the recurring "new per-side pool breaks export"
   bug — see LEARNINGS 2026-06-16.**
3. **Spine caption off-center in PDF** — engine rotates the caption box about its center
   (text centers on spine); PDF used `+ ascenderPt/2`, ignoring the descender → ~descent/2
   off. Changed to `+(ascent−descent)/2` to center the glyph line-box. (`export-pdf.js` ~995.)
   ⚠ **Least certain fix — Twinkle Star is a quirky script font; needs Evgeny's visual check.**
