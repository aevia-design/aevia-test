## What happened

### 1. PDF blank-line drop (root-caused via /systematic-debugging)
Evgeny confirmed S47's caption/PDF parity fixes look good (Intro size, spine centering,
Labour photos all correct). One remaining mismatch: the Intro page paragraphs had visible
blank-line gaps in the engine but ran together in the PDF.

**Root cause:** both PDF text-render paths in `scripts/export-pdf.js` deleted empty lines:
- text-panel wrap (~788): `flatMap(l => l.trim() ? wrap(l) : [])`
- per-photo captions (~709): `.split('\n').filter(l => l.trim())`

The engine renders stored `\n\n` as `<br><br>` (a visible empty line consuming one
line-height); the PDF dropped them, collapsing paragraph spacing.

**Fix (generic, all templates):** empty line preserved as `['']` (reserves one line-height
via the forEach index), skipped at draw time (`if (!line.trim()) return;`). Added the
draw-skip guard to the per-photo forEach (it lacked one; the panel path already had it).
valign centering unaffected — blank lines now count in the height measurement, matching the
engine's flexbox centering. Regenerated AEV-037 PDF (exit 0, 40 pages); Evgeny confirmed the
Intro spacing now matches the engine. Codified in LEARNINGS 2026-06-17.
