### 2. Closed book — spine fix (`scripts/compose-closed.mjs`)
Evgeny: spine read **black**, should be cover-blue with the engine caption; spine slightly
overhung the book.
- Root cause: the script flat-tinted the whole Book body navy then darkened edges with
  `Edge copy` multiply @0.45 → black; the real spine art (with the "Our Nicolas" caption)
  was never mapped on; the flat tint overhung the true spine extent.
- Fix: refactored the cover-warp loop into a reusable `warp()` helper. Calibrated the
  **spine-face quad** from the `Edge copy` layer's alpha extremes (the spine has no PSD layer
  of its own): hinge corners A`[403,746]`/B`[1107,1627]` == the cover's near-left edge;
  C/D = A/B extruded by the board thickness `[-4,+77]`. Extract the wrap's middle 9mm spine
  strip and warp it onto `[D,A,B,C]`. Dropped `Edge copy` multiply 0.45 → **0.18** (light
  depth only). Spine now reads cover-navy with the caption, flush with the book. **Approved.**

### 3. Back book — three-quad rewrite (`scripts/compose-back.mjs`)
Evgeny circled: (1) dark-blue band at front-cover bottom, (2) same on back cover, (3) greenish
line above the spine, and the book lacked the reference's **"folded / lying on its pages"** feel.
- Single root cause: the script warped the **whole wrap flat onto the full book silhouette**
  (`Pages` quad), painting over the page block and the fold.
- Fix: warp the wrap as **three pieces** onto three quads taken from the PSD's own shading-layer
  shapes — back 200mm → `Back cover` quad (left page), front 200mm → `Cover` (multiply) quad
  (right page), middle 9mm spine → `Edge ` quad (spine fold). Leave the `Pages` layer (real
  photographed page block) showing underneath → folded depth + covers overhanging the pages.
  Correspondence `[TL,TR,BR,BL]→[top,right,bot,left]` (proven by the old single-wrap ROT=0).
  Dropped the green `Edge ` multiply (it was the reference example's green spine).
- Note: the engine spine strip is genuinely **light blue `#c0d5ee`** (sampled from the wrap),
  not navy — so the light-blue spine fold is faithful, not a bug. **Approved.**

### 4. Shared backdrop — all three → soft off-white (`#f0f0f0`)
Evgeny: same background for all, white.
- Set `bg` to `255,255,255` first; surfaced two issues, both diagnosed by pixel-sampling:
  - **Open book pink wash:** the `Shadows` layer is neutral, but the `Back cover` multiply
    layer carries a warm drop-shadow `(251,237,237)` that tinted white. Added a `neutralize()`
    helper (rgb→luminance) and wrapped `Shadows` + `Back cover` in the open script.
  - **Open book blurry top-left page edge:** pure white (255) is **brighter than the paper**
    (~247–251), so page edges with no navy cover line behind them (the left page's far edge)
    washed out. Fix = drop the backdrop to **`#f0f0f0` (240)**, just below the paper tone, so
    every edge stays crisp. Applied to all three scripts. (This is why the reference PSD used a
    coloured backdrop, never 255.)
