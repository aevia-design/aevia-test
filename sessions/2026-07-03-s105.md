## 1. Logo-crop bug — FIXED (root cause found)
The v3 mockup logo rendered cropped (top/bottom cut) in Chrome. Root cause was **not CSS** and **not the logo asset**: the base64 PNG *baked into the mockup* was a corrupt copy — valid IHDR (409×101, proper IEND) but truncated pixel data, so browsers painted only the top slice at any size. Proven by rendering the embedded base64 vs the real file side by side at natural size (embedded clipped, file clean). Fix = re-encode base64 straight from `assets/images/logo - transparent.png` and swap into all headers. (Lesson reinforced: render + inspect, don't theorise — but also, a byte-length match is not an integrity check.)
