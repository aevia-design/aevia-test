### 11:30 — ARCHITECTURE.md + ADRs created

**Done:** `ARCHITECTURE.md` written covering system diagram, full codemap, key patterns (template-as-data-file, three-mode engine, Firebase backend), data flow for all 6 steps, 7 invariants, cross-cutting concerns, and dependencies. `docs/decisions/0001` and `docs/decisions/0002` created as ADRs.
**Decided:** ADR-0001 — Staff engine public hosting: Cloudflare Access (Zero Trust, OTP to allowed emails). Rejected HTTP Basic Auth (shared credential, no expiry, no audit trail, no per-user revocation — not appropriate given customer photos/data at stake).

**Watch out for:** Staff engine currently local only — Cloudflare Access setup needed before Xenia can use it remotely. Preview token implementation needed before `customer-preview.html` build can begin.
