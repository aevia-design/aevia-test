## Decisions made

- **Address = Firestore-owned** (data), but **Aevia-owned form** (entry) for signed-in users — corrects the Phase 2 implementation that let Stripe own the form.
- **Guests → Stripe collects address.** Don't add address UI to the token/preview flow (ADR-0007 augment-only). If a guest later signs up with the same email, the address is already theirs.
- **Pre-fill via `payment_intent_data.shipping`, never `shipping_details`** (read-only on create — verified).
- **Austria-only** country for both paths, deliberate trial-phase choice.
- **Order-form sign-in = inline modal**, not a redirect (preserves order context; no dead-end).
