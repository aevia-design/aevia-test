### — Caption typography moved to CSV + template-data.js
**Done:** Added `caption_font`, `caption_size_pt`, `caption_style`, `caption_letter_spacing`, `caption_line_spacing` columns to `Scribble_sizing_full.csv`. `csv-to-template.js` now reads these and emits them into every `caption:` object in template-data.js (both slot captions and textPanel captions). template-engine.html reads font/size/style/spacing from slot data and applies inline styles instead of relying on CSS defaults.
**Decided:** funnyWords text panel uses `sizePt * SCALE` (px) for font size; all other captions use `sizePt + 'pt'` directly. This preserves the existing visual scaling for the large kids-handwriting display.
**Watch out for:** The CSS `.slot-caption { font-size: 14pt }` and `.fp-text-panel { font-size: 16pt }` remain as fallbacks — they will not be seen in practice because inline styles always override. Do not remove them without testing.

### — Per-spread caption typography defaults
**Decided:** Standard spreads and FP3/FP4 → NT Somic, 14pt, regular, -0.02em, 1.28. FP1 birthday text panel → NT Somic, 16pt, regular, -0.02em, 1.28. FP2 funny words text panel → FirstTimeWriting, 20pt, regular, 0em, 1.2. FP5 art gallery → EB Garamond, 13pt, regular, +0.03em, 1.35.
**Why:** FP5 uses EB Garamond for a gallery-label aesthetic; staff can toggle italic per caption via the forthcoming toolbar. FP2 font is fixed (no toolbar) but size/spacing scale with word count (auto-scaling not yet built).

### — Caption multi-line fixed (innerText vs textContent)
**Done:** Switched caption save/restore from `textContent` to `innerText` in all three places (initial render, focus handler, blur handler).
**Why:** `textContent` strips `<br>` elements that Shift+Enter inserts in contenteditable — line breaks were lost on every blur. `innerText` round-trips `\n` ↔ `<br>` correctly.
**Watch out for:** Shift+Enter creates a new line; plain Enter still saves and closes (by design). Do not revert to `textContent` for caption elements.

### — SP6 left caption offset updated
**Done:** CSV changed from 20mm to 10mm below photo for SP6 left page captions; template-data.js regenerated.
**Why:** 20mm offset pushed the caption to the very bottom of the page — no room for a second line.
