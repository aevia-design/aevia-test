## Work done

1. **`saveMyAddress` Cloud Function** (`functions/index.js`) — new endpoint. Same auth gate as `getMyOrders`/`getMyAddress` (verified Firebase ID token + `email_verified`). Sanitises input to only stored fields (all strings), requires name/line1/city/postal_code, enforces `country === 'AT'`. Writes `shippingName` + `shippingAddress` to `customers/{normalizedEmail}` (`merge:true`) — same doc `getMyAddress` reads.
2. **`getMyAddress`** now also returns the saved `name` (so the form pre-fills it).
3. **`account.html` Address book → editable form.** Country-first ordering (per Evgeny — convention is country at top), Austria fixed/disabled, pre-filled from `getMyAddress`, inline success/error via the existing `.auth-msg` classes. Reuses `.field`/`.btn-primary` — no new form CSS.
4. **Geoapify autocomplete** (`@geoapify/geocoder-autocomplete@3`, MIT) via unpkg CDN — CSS link + script in `<head>`, `GEOAPIFY_KEY` const, `initAddressAutocomplete()` builds the widget on a search field at the top of the form, `addFilterByCountry(['at'])`, and on `select` fills line1 (street+housenumber), postcode, city. **Progressive enhancement:** if the global isn't present, it returns and the manual fields still work. "Powered by Geoapify" attribution added (free-tier requirement).
5. **`createCheckoutSession`** — removed the dead `sessionParams.shipping_details` block; split paths: saved-address customer → `payment_intent_data.shipping` + stamp `shippingAddress` on the order doc at create time; guests → `shipping_address_collection:['AT']` unchanged.

## Decisions made

- **Geoapify over OSM Photon** (`/solutioning` + `/verifying-claims`): managed, free 3,000/day, no credit card, EU (Cyprus → GDPR). Public Photon endpoint isn't production-safe; self-hosting Photon is over-engineering for a one-country trial. The earlier idea of a "static postal→city file now, Geoapify later" was dropped as two integrations where one will do (Evgeny's push — correct).
- **Skip Stripe's address collection for saved-address users** (so they never retype) and pass `payment_intent_data.shipping`. Because `session.shipping_details` is populated only by collection (verified against Stripe docs), the order's `shippingAddress` is stamped in `createCheckoutSession` at create time so staff/print still have it. Guests unchanged.
- **Country stays real data, not schema-baked** — Austria-only is a filter in ~6 spots, not a foundation. Expanding = turn the fixed country field into a dropdown + add codes. ~1 hour.
