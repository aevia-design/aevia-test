### 2. chunk-024 — server-side PDF generation (DEPLOYED)

**Design decisions (with Evgeny):**
- **Dashboard-only trigger** (no engine button this chunk). Engine→Save→dashboard Generate PDF.
- **Firestore as data source** (the `staffBook*` fields written by engine Save), NOT `book-state.json`/Export — closes the TO-DO #64 footgun.
- **Public Cloud Run URL for testing** (`--allow-unauthenticated`); harden to private + identity token before prod.
