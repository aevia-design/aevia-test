**PSD model (confirmed by rendering each layer):**
- Scene = `psd.canvas` composite (3000×2000). Per template change ONLY the cover face + front spine colour.
- `Main Image` = white 3D-lit book **form** (rounded corners, spine fold, baked soft shadow), region **[935,436] 1128×1127** = the cover-face swap target.
- `111` (front) / `""` (back) = the FLAT printed artwork wrap `[back|spine|front]`; the light-blue spine band (`#c0d5ee`) sits just LEFT of the Main-Image region on the front.
- `Layer 1` (multiply) + `Highlight` (screen, op 0.145) = lighting; `Shadow` (linear burn) + `BG texture` = drop shadow + backdrop.

**Algorithm (in the script):**
1. Base = `psd.canvas`. Extract order cover face from `sessions/qa-runs/cover-wrap-<order>.png` (front = right 200/409, back = left 200/409 → 1128×1127).
2. Overwrite the Main-Image region with the face; reapply Layer 1 (multiply) + Highlight (screen×0.15). Skip a thin spine window on the front (`FRONT_SPINE {xLo:930,xHi:938,featherTo:943}`).
3. **Step 2b bottom-edge bevel fix:** rows just below MI (y≥1563) render the newborn navy edge → bleeds on colour templates (incl. a butterfly-tip remnant). Recolour ONLY cool-navy bevel pixels (`b>r+4`) to the cover colour, luminance-preserved. Follows the real corner geometry; keeps the white edge highlight + backdrop/shadow. Identity for newborn.
4. **Step 3 front spine recolour:** in the spine window, remap light-blue (`(b-r)>20 && b>150 && g>r`) → template spine colour, scaled by luminance (`NB_SPINE_LUM ≈ 210`). Identity for newborn.
5. Back = **face-swap only, no spine recolour** (see below).
6. `--scratch` flag: writes PNG to `mockups/<order>/` but SKIPS the `assets/` webp write. I used `--scratch` on every run this session, so `assets/` is untouched.

**Spine colours:** newborn `#c0d5ee`, wander `#86A37B`, scribble `#fdd16f`, papercut `#8bb8d8`, tender `#fbf8f6`.
