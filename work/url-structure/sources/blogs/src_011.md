# Google Revises URL Parameter Best Practices

Source: https://www.searchenginejournal.com/google-revises-url-parameter-best-practices/530814/
Author: Matt G. Southern, Senior News Writer
Publisher: Search Engine Journal
Publication date: 24 October 2024
Retrieved: 2026-09-23 via WebFetch (summarized extract)

## What Changed

Google updated Search Central documentation to consolidate URL parameter formatting recommendations: use "=" to separate key-value pairs and "&" to connect multiple parameters, discouraging non-standard separators (colons, brackets, commas). Previously this guidance lived only in an older blog post about faceted navigation; it is now part of the main Crawling and Indexing documentation section.

## Impact

Google has not stated these changes directly affect rankings, but proper formatting prevents crawling inefficiencies and indexing issues — particularly relevant for ecommerce sites and CMSs using parameters for filtering, sorting, tracking. Google advises sites using non-standard formats to plan migrations with proper redirects while monitoring crawl statistics during transition.
