# Managing Multi-Regional and Multilingual Sites

Publisher: Google Search Central (Google for Developers)

## URL Structure Options

**ccTLD** (e.g. `example.de`): Clear geotargeting, server location irrelevant, straightforward site separation. Weaknesses: high cost/limited availability, greater infrastructure demands, targets only one country.

**Subdomain with generic TLD** (e.g. `de.example.com`): Simple setup, flexible server locations, easy site isolation. Weakness: users may struggle to recognise geographic intent from the URL alone.

**Subdirectory with generic TLD** (e.g. `example.com/de/`): Straightforward implementation, minimal upkeep on a single host. Weaknesses: reduced user clarity on geotargeting, single server location, more complex site separation.

## Key Recommendation

Avoid URL parameters like `site.com?loc=de` — segmentation is difficult for these. For generic TLDs, explicitly communicate geographic targeting via hreflang, clear URL structure, or other explicit signals.
