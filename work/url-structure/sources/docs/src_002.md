# Ecommerce URL Structure Best Practices

Source: https://developers.google.com/search/docs/specialty/ecommerce/designing-a-url-structure-for-ecommerce-sites
Publisher: Google Search Central (Google for Developers)
Retrieved: 2026-09-23 via WebFetch (summarized extract)

## Key Principles

Google recommends structuring URLs to help crawlers efficiently locate and index pages while avoiding duplicate content issues.

## Category/Product Hierarchy

Each page in paginated results should have a unique URL. For product variants, use either path segments (`/t-shirt/green`) or query parameters (`/t-shirt?color=green`).

## Meaningless Path Segments

Google explicitly discourages numerical or cryptic identifiers: "Add descriptive words in URL paths. The words in URLs may help Google better understand the page."

- Recommended: `/product/black-t-shirt-with-a-white-collar`
- Not recommended: `/product/3243`

## IDs vs Words

The guidance favours human-readable, descriptive text over numeric IDs. Words in URLs assist Google's understanding; meaningless numbers provide no semantic value.

## Query Parameter Best Practices

Use structured key-value pairs rather than standalone values:
- Recommended: `/photo-frames?page=2`, `/t-shirt?color=green`
- Not recommended: `/photo-frames?2`, `/t-shirt?green`
