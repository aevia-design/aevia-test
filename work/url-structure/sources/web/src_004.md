# URL as UI

Source: https://www.nngroup.com/articles/url-as-ui/
Author: Jakob Nielsen
Publisher: Nielsen Norman Group (NN/g)
Retrieved: 2026-09-23 via WebFetch (summarized extract)

## Key Principles

**Readability & Guessability**: domain name should be easy to remember and spell; keep URLs short, easy to type, avoid mixed case (use all lowercase); structure URLs to visualize site hierarchy.

**Trustworthiness**: Research from Microsoft found users spend 24% of their gaze time looking at URLs in search results. Users assess credibility through URLs — "when the URL looks like garbage, people are less likely to click" on search results. A professional-looking, relevant URL increases click likelihood.

**Length**: Keep URLs under 78 characters to prevent wrapping in email, the second-most common way users discover sites.

**Persistence**: Never move pages or change URLs. Linkrot causes "lost business"; maintain permanent URLs pointing to relevant content.

**Domain Strategy**: Use .com for English-language, worldwide sites; use country-specific domains for local sites to avoid misleading users about scope.

## Core Insight

URLs function as visible UI elements, not hidden technical infrastructure, and deserve careful design consideration.
