# Real-world observation: Mixbook and Saal Digital URL structures

Retrieved: 2026-09-23 via WebFetch (direct observation)

## Mixbook — https://www.mixbook.com/
Homepage is the bare root domain. Product categories are flat, one level under root, descriptive:
- `/photo-books`, `/all-photo-books`
- `/photo-gifts`
- `/magazines`
- `/photo-calendars-home`, `/photo-calendars`
- `/cards`, `/cards/all`
- `/home-decor`, `/home-decor/canvas-prints`, `/home-decor/metal-prints`, `/home-decor/poster-prints`
- `/the-wedding-shop`
- `/education-photo-books`
- `/pro-collection`
- `/try-story-mode`

## Saal Digital — https://www.saal-digital.com/
Homepage is the bare root domain. Product categories flat, one level under root, trailing slash, descriptive:
- `/photo-book/` (with `/photo-book/professional-line/`, `/photo-book/one-minute-photo-book/`)
- `/wall-art/`
- `/prints/`
- `/poster-fineart/`
- `/cards/`
- `/photo-gifts/`
- `/photo-calendar/`
- Configurator tool lives at a deep, technical path: `/WebshopConfigurator/#/.../en/Categories/` (an app, not a content page — the one place a "meaningless" path segment appears, on a tool rather than a content page).

## Note
Raw observational data (live URL snapshots), not an editorial/documentation source. Both brands put the homepage at the bare root domain and use short, flat, descriptive category slugs — no CMS/page-type prefix (e.g. no `/pages/`, `/shop/`, `/collections/` wrapper).
