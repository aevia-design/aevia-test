# Google for Developers - Updates to the Google Photos APIs (official)

Source: https://developers.google.com/photos/support/updates
Accessed: 2026-09-24 (WebFetch extract, official Google documentation)

## Extracted content
Effective date: 31 March 2025 (all changes take effect).

Removed scopes from the Library API:
- photoslibrary.readonly
- photoslibrary.sharing
- photoslibrary

Remaining/unaffected scopes:
- photoslibrary.appendonly
- photoslibrary.readonly.appcreateddata
- photoslibrary.edit.appcreateddata

After the cutover, the Library API only lets an app list, search, and retrieve albums/media items that THAT APP itself created or uploaded - it can no longer browse a user's full existing library.

Google Photos Picker API (the replacement): "a new, secure way for developers to let users select photos and videos from their Google Photos Library, and seamlessly send them back to your application." It requires manual, per-session user selection (no automated/background sync) and is explicitly positioned as a privacy-preserving alternative.

Migration guidance: "For photo selection: migrate to the Google Photos Picker API. For other functionalities: review the updated Library API documentation." API calls relying only on the removed scopes now return 403 PERMISSION_DENIED.
