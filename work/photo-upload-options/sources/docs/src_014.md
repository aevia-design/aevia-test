# Google for Developers - Overview of the Google Picker (Drive)

Source: https://developers.google.com/workspace/drive/picker/guides/overview
Accessed: 2026-09-24 (WebSearch snippet aggregation; official Google documentation)

## Extracted content
The Google Picker is described as a "File Open" dialog for Google Drive content: a JavaScript API/web component letting users select (or upload) Drive files into a third-party web app. Setup requires enabling both the Google Picker API and the Google Drive API in a Google Cloud project, plus standard OAuth 2.0 consent for the requested Drive scopes. Returns file metadata (IDs, URLs) to the integrating app once the user picks.

Two integration paths exist: a newer "web component" (wraps API loading/auth boilerplate into one HTML element, framework-agnostic) and the older direct JavaScript API (more manual control, e.g. multi-select, hiding the nav pane).

## Notes
This is the Drive-equivalent of the Google Photos Picker API (src_011) and is architecturally similar to Dropbox's Chooser (src_013) in outcome (user picks files, app gets URLs/metadata back) but requires full OAuth 2.0 consent-screen setup and Google Cloud project configuration - meaningfully heavier to stand up and maintain than Dropbox's no-OAuth Chooser, and subject to Google's OAuth app verification requirements once scopes beyond the most basic are requested. Relevant baseline for comparing "add Google Drive" vs "add Dropbox" cost, since the site copy currently promises both.
