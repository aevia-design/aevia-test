# CEWE - Aus der Cloud ins CEWE FOTOBUCH (Cloud photo import tutorial)

Source: https://www.cewe.de/inspiration/tutorial-aus-der-cloud-ins-cewe-fotobuch.html
Accessed: 2026-09-24 (WebSearch snippet aggregation)

## Extracted content
CEWE's desktop software (CEWE Fotowelt) lets customers import photos from cloud services in addition to local files: Dropbox, CEWE myPhotos, and (formerly) Google Photos are named as supported "Online-Fotoquellen" (online photo sources), selected via Options > Fotoquellen menu. OneDrive and Apple Photos/iCloud photos stored via connected drives are also picked up automatically by the desktop software when present on the machine.

## Notes
CEWE is the Austria/Germany market leader and offers the broadest cloud-source integration of any competitor found, but this is achieved through a heavyweight downloadable desktop application (CEWE Fotowelt), not the web browser - a materially different (and higher-effort) integration path than a pure web order form like Aevia's.
