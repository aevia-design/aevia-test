# Shutterfly Help Center - Uploading Photos Guide & Resolution Recommendations

Source: https://support.shutterfly.com/s/article/uploading-photos-guide
Accessed: 2026-09-24 (WebFetch extract)

## Extracted content
Supported upload sources (explicit):
- Computer / device file picker
- Google Photos (connect account, browse All Photos and Albums, select then upload)
- Amazon Photos
- Facebook (log in, select album/photos)
- Mobile app camera roll

Explicitly NOT supported: file storage services such as Google Drive, Dropbox, or FTP. Quote: "Shutterfly currently does not support file storage services such as Google Drive, Dropbox, or FTP." Users are told they can upload directly from Google Photos and Facebook/Instagram, but not from Dropbox or Google Drive cloud storage.

Formats accepted: JPG, JPEG, PNG, BMP, HEIC, HEIF (HEIC/HEIF only via iOS app, website, and mobile web). Not accepted: .tif/.tiff/.gif/.psd/.pdf.
Video: up to 2GB, various formats.
Photo storage: unlimited for active customers.
Facebook-sourced photos are noted as reduced resolution, unsuitable for large prints.

## Notes
This is the single clearest primary-source statement found that a major, long-established photo-book competitor (Shutterfly) deliberately does NOT support Dropbox or Google Drive as upload sources - directly relevant to Aevia's question of whether to drop that promise. High authority (official support article), current.
