# Popsa - Photo Sources (Google Photos, Dropbox, Facebook, Instagram)

Source: https://support.popsa.com/hc/en-gb/articles/360014472298-Select-photos-from-other-apps ; https://popsa.com/perspectives/how-to-make-photo-book-on-phone/
Accessed: 2026-09-24 (WebSearch snippet aggregation; direct WebFetch of the help-centre article returned HTTP 403)

## Extracted content
Popsa (mobile-app-first photo book service) integrates directly with Google Photos, Dropbox, and Facebook/Instagram, pulling images from multiple sources into one project without requiring the user to download and re-upload manually. Google Photos is noted as the only source offering in-app search. Camera roll / iCloud photos on-device require no separate integration since they're already local to the phone.

## Notes
Popsa is the one competitor found that explicitly names Dropbox as a working, integrated source (not just device + Google Photos). However, Popsa is an app-first product (native iOS/Android), which can request native OS-level photo/file permissions unavailable to a pure web order form - an important technical caveat for comparing to Aevia's browser-based flow.
