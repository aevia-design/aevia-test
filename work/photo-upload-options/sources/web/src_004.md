# CEWE Community Forum - "Abschaltung von Google Fotos" (Google Photos shutdown notice)

Source: https://www.cewe-community.com/forum/fb/viewtopic.php?f=55&t=16635
Accessed: 2026-09-24 (WebFetch extract). Forum post dated 2025-04-04.

## Extracted content
As of 1 April 2025, CEWE could no longer directly integrate Google Photos into its ordering systems, citing "new security guidelines from Google" (this aligns with Google's Library API scope removal on the same date - see src_009/src_010).

CEWE's response by platform:
- Website/software: customers must now download photos locally first, then upload; existing projects that already reference Google Photos images keep working.
- Android app: photos must be stored locally on-device; no more direct Google Photos picker.
- iOS app: existing projects continue working, but new images require a local download step first.

Quote (German): "Ab dem 1. April 2025 koennen wir diese leider nicht mehr direkt in unsere Bestellsysteme einbinden."

## Notes
This is direct, dated, primary evidence that Google's 2025 API changes (not a business choice) broke a live cloud-source integration at the market-leading competitor, forcing a fallback to manual download-then-upload - the same UX Aevia's own order form already offers today for cloud sources.
