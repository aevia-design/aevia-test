# memoryKPR - Instagram API Deprecation: Manual Content Import Ending Dec 4 [2024]

Accessed: 2026-09-24 (WebSearch snippet aggregation)

## Extracted content
On 4 December 2024 the Instagram Basic Display API - the API that let personal (non-business) Instagram accounts grant read-only access to their own photos/videos to third-party apps via simple OAuth - reached end-of-life and was switched off outright (not merely deprecated-but-working). Any integration calling graph.instagram.com Basic Display endpoints with personal-account tokens now fails. The replacement (Instagram Graph API / Instagram Login API) only works for Creator or Business accounts, not ordinary personal accounts - which describes the vast majority of Aevia's customers.
A named casualty: the Day One journaling app announced it would no longer be able to import users' Instagram photos/posts.
