# Xenia's flow — Aevia marketing sparring partner

## One-time setup (Evgeny does this with you, ~15 min)
1. Your Claude account on the Pro plan, Claude Desktop app installed.
2. Install the marketing skill pack on YOUR account: claude.ai → Settings →
   Customize → Plugins → Browse plugins → add custom marketplace →
   `coreyhaines31/marketingskills` → install. (One click; Evgeny has done it once
   already on his account and can drive.)
3. Create a folder `Aevia Marketing` (inside a synced drive if you want Evgeny to
   see the same files). Put `folder-instructions.md` content into Cowork's folder
   instructions for it, and keep a copy in the folder root.
4. Open Claude Desktop → Cowork → select the `Aevia Marketing` folder. That's your
   workspace from now on. Files Claude writes appear in the folder like normal files;
   everything is still there next session.

## Session 1 — it interviews you (~45–60 min)
You are not asking the AI for a strategy. It is asking YOU about your business.
Paste this to start:

> Run the product-marketing skill. Interview me to build Aevia's
> product-marketing.md context file — one question at a time, follow-ups where my
> answer is thin. I'm the strategist; you're capturing MY read of the product,
> customer, and positioning. Where my reasoning seems weak, challenge me — but the
> decisions recorded are mine. When we're done, write the file and show me what
> you wrote before saving.

What you get: `product-marketing.md` — your own positioning brief, in the folder,
which every other skill reads before doing anything. Correct it freely; it's yours.

## Session 2 — the council (~30 min)
Bring one real decision you're currently unsure about (a channel, the price, the
launch approach — anything live). Paste:

> Convene the marketing council on this question: [your question]. Seat 3–5
> advisors whose lenses genuinely conflict, including at least one who will
> disagree with where I'm leaning. I want each advisor's reasoning from their
> documented frameworks, the disagreement between them made explicit, and only
> then a synthesis. Do not converge politely.

This is a simulated board (Ogilvy, April Dunford, Byron Sharp, Rory Sutherland…),
each grounded in what they actually wrote. The value is the disagreement.

## Session 3 and on — the plan, section by section
Paste:

> Run the marketing-plan skill for Aevia. Work from product-marketing.md. Draft
> one section at a time and stop for my verdict — I will approve, change, or
> reject each section. Where you rely on an assumption, log it in assumptions.md
> with confidence and the cheapest way to test it. Every spend recommendation
> needs evidence, a cost cap, and a kill criterion, or don't make it.

The skill keeps its own progress file — if a session ends mid-plan, the next one
resumes where you stopped. The finished plan is one you approved line by line.

## Four moves worth knowing (use any time)
- **Fresh eyes:** open a NEW session, paste any draft, say: "You didn't write this.
  Tear it apart." A fresh session has no stake in its own work and won't defend it.
- **Demand the kill criterion:** if it recommends spending anything without "stop
  if X by Y", say "kill criterion?" — it knows it owes you one.
- **Source or silence:** any number without a named source and year — ask for one.
  "Where is that from?" is always a fair move.
- **Steelman the opposite:** "Make the strongest case AGAINST what I just decided."
  Cheap, fast, and occasionally saves real money.

## What this is not
It will not make decisions, run your ads, or post content. It researches, computes,
critiques, and remembers. The strategy is yours.
